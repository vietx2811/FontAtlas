## 2. Cửa sổ và vibrancy (Tauri 2)

Hiện trạng trong `tauri.conf.json` (main): đã có `"transparent": true` và `"titleBarStyle": "Overlay"`.

**Việc cần làm:**
1. Thêm hiệu ứng sidebar của macOS bằng **config** (đã kiểm mã nguồn `tauri` 2.9.5 / `tauri-utils` 2.8.1, không cần crate `window-vibrancy` riêng):
   - Cửa sổ `main`: `"transparent": true`, `"windowEffects": { "effects": ["sidebar"], "state": "followsWindowActiveState" }`.
     - `WindowEffectsConfig` có `effects`, `state`, `radius`, `color`.
     - `WindowEffect` đổi tên camelCase nên ghi `"sidebar"`.
     - Tauri tự gọi `window_vibrancy::apply_vibrancy` khi tạo cửa sổ (`tauri/src/vibrancy/macos.rs`).
   - `app.macOSPrivateApi: true`. Bắt buộc cho `transparent` trên macOS (doc của `transparent` trong `tauri-utils`).
   - `UX/src-tauri/Cargo.toml`: `tauri = { version = "2.9.5", features = ["macos-private-api"] }`. Feature phải khớp config, nếu không `tauri-build` báo lỗi.
   - Hệ quả: dùng private API thì app không lên được Mac App Store. Phân phối ngoài store không ảnh hưởng.
2. Đặt `html` và `body` có `background: transparent`. Vùng nội dung (tấm "sheet") có nền đặc `--sheet`.
3. `titleBarStyle: Overlay` làm nút đèn giao thông nằm đè lên góc trái trên. Hàng trên cùng của sidebar phải:
   - chừa khoảng **78px** bên trái;
   - cao **≥ 38px**;
   - có `data-tauri-drag-region` để kéo được cửa sổ.

   Prototype chưa thể hiện phần này. Khi làm thật, nút thu gọn đặt ở bên phải hàng này, giống Claude desktop.
4. Khi cửa sổ không active, vibrancy tự nhạt đi (`followsWindowActiveState`), không cần xử lý thêm trong CSS.

```
│        └─ TabBody
```

**State:** dùng `zustand` (đã có trong dependencies) cho UI state. `App.tsx` hiện có 18 lần gọi `useState`; chuyển hết vào `useUiStore`:

```ts
interface UiState {
  view: 'all' | 'star' | 'recent' | 'active' | `col:${string}` | `src:${string}`;
  tag: string | null;
  query: string;
  viOnly: boolean;
  layout: 'grid' | 'list';
  sample: string;           // mặc định "Phở bò Hà Nội"
  sampleSize: number;       // 18–72, mặc định 34
  selectedId: string | null;
  style: string | null;     // tên subfamily đang chọn trong family
  panelTab: 'spec' | 'vi' | 'anat' | 'sim' | 'pair';
  sidebarCollapsed: boolean;
  openSections: { col: boolean; src: boolean; tag: boolean };
  infoExpanded: boolean;
}
```

- `selectedId` là khoá face `${hashHex}:${faceIndex}` (khớp `FaceRow`), không dùng id cũ của bảng `fonts`.
- Lọc không chạy phía client: `view`, `tag`, `query`, `viOnly` được chuyển thành `GridQuery` cho `PagedFaces` / `query_faces` (Plan 5). `col:`/`src:` mang id số của collection/nguồn trong store.
- Lưu `sidebarCollapsed`, `openSections`, `layout`, `sampleSize` và `infoExpanded` vào bảng `u.settings` có sẵn qua `Store::setting` / `set_setting` [6a: `get_setting`, `set_setting`], khoá dạng `ui.sidebarCollapsed`. **Không nâng `user.db` version**: Plan 7 độc quyền v2.
